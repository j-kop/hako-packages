# Security policy

This is a personal demo registry for [hako](https://github.com/j-kop/hako-source). It isn't meant to be used by anyone else, and it doesn't accept contributions.

If you notice a problem with one of its entries, such as a manifest pointing at a tampered file, report it privately: go to this repository's **Security** tab and click **Report a vulnerability**. Security problems in hako itself belong in [hako-source](https://github.com/j-kop/hako-source/security/advisories/new).
